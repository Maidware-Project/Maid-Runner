# Usage

## Launch and control
```sh
maid-runner
maid-runner --toggle
maid-runner --service
maid-runner --quit
```

## Search sources
- Applications (XDG desktop entries)
- Menu/category groups
- Maid actions (when Maidware tools are installed)
- Files (home directory names, in-memory while running)
- Run (PATH commands)
- Calculator (safe arithmetic)
- Web (prefixes/bangs/URLs, SearXNG for general queries)

## Keyboard/UI
- Type to search, Enter to run/open
- Esc or outside click to close
- Tab/Shift+Tab to browse tabs (empty query)
- Caps Lock cycles palettes

## Palettes
```sh
maid-scroll list
maid-scroll next
maid-scroll set tokyo
``` (or via app keybinding behavior)
