# Maid Runner Wiki

Maid Runner is a Qt launcher/search UI for Linux desktops with unified search across apps, files, commands, web (SearXNG), and Maidware actions.

## Contents
- [Installation](Installation.md)
- [Usage](Usage.md)
- [Troubleshooting](Troubleshooting.md)

## Highlights
- Fast resident/toggle workflow
- Category-aware app browsing and unified typing search
- Palette themes via Maid Scroll
- Desktop/compositor-agnostic core with environment-specific keybinding setup
